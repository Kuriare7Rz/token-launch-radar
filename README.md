Token Launch Radar ranks 200 pre-token protocols by implied value, derived from TVL, 7-day growth and age without a token — with concrete farm plans for the 40-protocol watchlist and a sortable, filterable dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
